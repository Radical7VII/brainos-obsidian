# BrainOS Graph for Obsidian

一份普通 Markdown 文件就是一次思考；这次思考的节点标题、正文和关系都保存在文件里。新增节点不创建独立笔记。节点可以在同一思考中连线，也可以通过 Obsidian 块引用复用其他思考中的节点。

## 使用

- 在 Obsidian 原生命令面板（`Cmd/Ctrl + P`）运行插件命令 **BrainOS Graph：新建思考**，创建 `未命名思考.md` 并在新 tab 打开思维视图。同名时要求另取名称，不覆盖、不自动编号。
- 标题栏的分支图标将当前 Markdown 切换成思维视图；铅笔图标切回原生 Markdown，并恢复先前的模式、光标和滚动位置。没有接管 `.md` 的默认打开方式。
- 双击空白，直接在新圆点下编辑标题。`Tab` 延伸子节点，`Enter` 创建同级节点；标题输入时 Enter 确认，Tab 确认后继续延伸，Esc 取消。中文输入法合成期不提交，空草稿不落盘。
- 双击节点或按空格编辑其标题和正文，只更新所属思考文件中的这一段。
- 在 tab 更多菜单、节点右键菜单或命令面板选择 **引用已有节点**。选中节点时建立到引用节点的关系；未选中时把引用节点加入当前图谱。选择同名节点时按所属思考区分，不自动合并标题相同的节点。
- `Alt` 从节点拖到节点创建关系；可跨节点来源组合，在当前思考中保存关系。引用内容从来源文件读取，编辑引用节点会更新来源节点，编辑器会显示来源。
- 删除本地节点会移除其正文及当前思考中的相邻关系；移除外部引用保持来源节点完整。两者均先显示确认。断开关系保留正文里的可读文字，不自动把前后节点连接起来。
- 画布只常驻搜索、设置两个图标。适配（`F`）、刷新、Session 和其他操作位于原生更多菜单。

普通 Markdown 也可以直接切换思维视图。第一次添加节点会在当前文件追加节点区域并标记为思考文件，保留原有正文，不另建文件。

## Markdown 格式

```md
# 如何让记录更自然

## 节点

**为什么要做这件事** ^node-start

让记录跟上思考的速度。

**减少打断** ^node-flow

创建时直接写标题，正文随后补充。

## 关系

- [[#^node-start|为什么要做这件事]] → [[#^node-flow|减少打断]]
- [[#^node-flow|减少打断]] → [[其他思考.md#^node-feedback|及时反馈]]
```

节点是段落，不靠标题层级表达树深度。标题使用独立粗体段落，正文可包含多段文字、标题、列表、代码和普通内部链接。稳定的块 ID 由插件生成，标题改名不改变节点身份；相同标题可以对应不同节点。

手写时可在 `## 节点` 下直接写 `**节点标题**` 和正文，首次通过插件编辑或引用时自动补齐块 ID。独立粗体段落作为节点分隔；作为格式示例时请放进代码块。`## 节点`、`## 引用`、`## 关系` 是保留的区域标题。

未连线的外部引用保存在 `## 引用` 列表；连线保存在 `## 关系`，节点正文中的 Wikilink、块嵌入和本地 Markdown 链接也参与构图。跨思考引用不复制节点正文，来源失效时显示未解析节点，不生成占位文件。

这些链接采用 [Obsidian 官方内部链接和块引用](https://obsidian.md/help/links)；普通 Markdown 阅读器仍能阅读标题、正文和关系文本，但不一定能跳转 Obsidian 块链接。节点内容以 Markdown 正文为唯一来源，没有另一份 JSON 正文副本。

## 旧格式

旧 `.thought.md` 及 `brainos-state` 思考仍可读取。首次编辑或引用旧思考时，把原来分散的节点正文和路径收进思考文件，保留文件说明及草稿，之后按单文件格式编辑。原来的节点文件不自动删除；状态损坏或转换期间文件变化时拒绝覆盖。

## 全库图谱与布局

「打开 BrainOS 图谱」继续提供独立的全库视图。笔记双链通过 `metadataCache` 构图；设置可切换为各思考内部的思维节点。全库笔记双链不再提供逐节点新建文件，创建节点应先进入一个思考文件。

布局使用原创 Worker、Barnes–Hut 排斥、度数偏置弹簧和预测碰撞；悬停邻域高亮、标签缩放淡出、主题色和触摸操作保留。坐标、视野、设置及 Session 记录保存在插件数据中。静态分析依据与复刻边界见 [图谱优化记录](docs/GRAPH_RECONSTRUCTION.md)。

## 构建和安装

```sh
npm install
npm run build
npm test
```

将 `manifest.json`、`main.js`、`styles.css` 输出到 vault 的 `.obsidian/plugins/brainos-graph/`。本地部署目标为 `/Users/othnielsu/Documents/OSLib/.obsidian/plugins/brainos-graph/`，保留已有 `data.json` 和启用配置；已启用插件需要重载后使用新版。

原生数据库、语音、Keychain 和 Live 会话未移植；`src/ai.ts` 仅保留 provider 接口，当前不会发送内容。浏览器交互验证使用合成思考与 Obsidian API 模拟层，尚未进行安装后 Obsidian 真机交互验证及大型 vault 性能基准。
