# BrainOS Graph for Obsidian

把 BrainOS 的思考工作流带进 Obsidian vault。**一份思考就是一个 Markdown 文件，每一行文字就是一个节点**：缩进表示父节点指向子节点，相同文字的节点在图谱里共用同一个元素。图谱坐标保存在插件数据里，不修改 `.obsidian/`。

## 模型

```text
用户反馈
    文件太细碎，希望整组输出
编辑体验
    输入时实时渲染
    支持快捷键
    文件太细碎，希望整组输出
        整组导出为文本大纲
```

- 每个非空行是一次节点出现；缩进表达父子关系，同级行不自动连边。
- 相同文字共用一个节点；改名会改掉该思考里这个文字的所有出现。
- 在新节点、改名、连线、删除都写回这份思考的大纲文件，不会为单个节点新建 `.md`。
- 一个思考文件 = 一份 `<标题>.md`，默认放在 vault 根目录（可在设置里指定文件夹）。

## 功能

- 通过 `metadataCache` 与 BrainOS 的身份缓存找到思考文件（`.thought.md`、`brainos_type: thought-file`、`.brainos/thoughts/.state` 缓存、插件新建或设置文件夹内的 `.md`）
- 从大纲行生成可编辑图谱：节点按文字合并，连线来自缩进
- 双击空白或点击「新建节点」在当前思考里追加一行；未选择思考时自动新建一份思考文件
- 选中节点后按 `Tab` 延伸子节点、`Enter` 创建同级节点、空格编辑这一行
- `Alt` 从一个节点拖到另一个节点创建连线（在来源下面插入一行目标文字）
- `Delete` / `Backspace` 删除当前思考里的这一行及其子行
- 双击节点打开所在思考文件；拖动节点保存布局，拖动空白平移，滚轮缩放
- 工具栏可切换当前思考、搜索节点、刷新图谱和聚焦当前文件
- 旧的 `.thought.md`（含 `brainos-state`）会按其中的引用读出节点；下次写入时迁移成逐行大纲
- 文件变化后自动刷新图谱

### 图谱操作

| 操作 | 结果 |
| --- | --- |
| 双击空白 / 新建节点 | 在当前思考追加一行；没有思考时先新建一份思考文件 |
| `Tab` | 在选中节点下面加一个子行 |
| `Enter` | 在选中节点后面加一个同级行 |
| `Alt` 拖动节点到节点 | 在来源节点下面加一行目标文字（连线） |
| 空格 / 右键节点 | 编辑这一行的文字 |
| 双击节点 | 打开所在思考文件 |
| `Delete` / `Backspace` | 删除这一行及其子行 |

## 构建

```sh
npm install
npm run build
```

将 `manifest.json`、`main.js`、`styles.css` 复制到 vault 的 `.obsidian/plugins/brainos-graph/`，在 Obsidian 设置中启用插件。
